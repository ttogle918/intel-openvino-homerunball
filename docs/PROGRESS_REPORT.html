동작 규칙: run은 비상정지면 즉시 estop. 홈 확인 → 정책 phase → oranda_pickup이면 lift → home, dori_dori면 home. oranda_pickup은 GripperWatch.done 또는 max_time_s에서 끝난다(stop_reason: gripper_open / timeout).

SO101 import: physicalai 0.3.0 본체 physicalai.robot.so101를 먼저 쓰고(Studio 백엔드와 같은 경로) 플러그인은 예비다(5a30392). requirements-robot.txt에서 플러그인은 뺐다.

미해결 설계 숙제: 런타임이 카메라를 잡고 있는 동안 화면 영상·개수 세기를 어떻게 할지(설계 11.5절).

M4-4 현장 도구 완료

만든 것(2cdd395, 9563b9f, sonnet 리뷰 승인): tools.fetch_calibration은 Studio에서 팔로워 SO101의 캘리브레이션을 GET만으로 조회해 calibration/follower.yaml로 저장한다. tools.robot_probe watch는 토크를 끄고 관절값을 실시간으로 보여 주고, save home|lift는 포즈를 저장한다. 예외가 나도 disconnect(팔 자세 유지)하고 오류는 한국어로 안내한다.
