PERCEPTION

인식: OpenCV로 오란다만 세기

학습 없이 색·크기·위치 규칙만으로. 한 번 세는 데 약 17ms

파란 틀 = 매트 영역(ROI), 노란 상자 = 오란다로 센 것 → 3개 (노란 볼·초코송이 제외)
사진 5장을 0.1초 간격으로 세어 중앙값 → 손·흔들림에 강하다.
옮기기 전후 개수가 줄면 성공, 안 줄어도 그리퍼가 쥐었다 놓았으면 성공.

ACTION

행동: ACT 정책을 OpenVINO로

physical-ai-studio에서 녹화·학습 → OpenVINO로 내보내 노트북 CPU에서 추론

놓는 순간을 그리퍼 값으로 감지 (0 닫힘 ~ 100 열림, 실측)
닫힘 → 열림이면 ACT 멈춤 → 코드가 lift → home. 녹화 31개로 시뮬레이션: 23개 놓는 순간 정지, 조기 정지 0
정책 입력
  • 관절 6개 + 카메라 3대(위쪽 · 사이드 · 손목), 384×384 레터박스
  • 출력: 100스텝 관절 목표(약 3.3초 분량)
도리도리
  • 학습한 도리도리 모델은 실기에서 몸통을 ±1만 움직임
  • 거부 · 채팅은 코드 도리도리(몸통 ±15, 2회), 버튼으로 모델도 시험

  • 말과 동작 동기: 대사 소리가 나기 시작하면 팔이 움직인다
